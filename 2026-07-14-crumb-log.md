# Crumb Log — Tuesday, July 14, 2026

*Session wrapped ~9:00 PM.*

## What happened today

**Assessed the old prototype.** Reviewed `smart-cookie-handler/` (the
copy-paste-from-chat era). Verdict: not shippable — files still had chat
wrappers (invalid `manifest.json`), site preferences read the extension's own
hostname instead of the site's, substring button matching could classify
"Continue without accepting" as *accept*, and "AI-powered" was keyword lists.
Decision: start over rather than fix.

**Went back to first principles.** Key insight from discussion: most banners
come from a handful of CMPs, and the risky part of any auto-clicker is the
clicking. The real open question is whether the long tail of nonstandard
banners is a nuisance worth building for — answerable with data, not vibes.

**Chose the hide/log model.** Hide banners without ever clicking (no click =
no consent given), log every sighting locally, and let a few weeks of
browsing data decide whether the ambiguous tail justifies an AI tier
(Chrome's on-device Prompt API is the candidate, per README roadmap).

**Built Banner Scout v0.1.0** in a fresh git repo (`extension/`):

- Conservative detection: word-boundary topic + action matching, overlay
  requirement (fixed/sticky/high z-index), must have controls.
- Risky candidates (login-like inputs, ToS wording without "cookie") are
  logged but left visible.
- Popup: global hide toggle (off = log-only), per-site kill switch, stats,
  recent log, JSON export. All data stays in `chrome.storage.local`.

**Tested before committing** against a live harness page (real banner,
late-injected banner, login modal, cookie-recipe article). Caught and fixed
two real bugs:

1. Elements evaluated while invisible were permanently skipped — but CMPs
   often inject banners hidden and reveal them later. Now only *acted-on*
   elements are marked handled, and the observer watches class/style changes.
2. Adjacent inline buttons concatenate in `innerText` ("AgreeDecline"),
   defeating word-boundary matching. Button labels are now checked
   individually.

Final result: both banners hidden and logged; login modal and article left
untouched. Committed as `aedc62f`.

**Named the agent.** The user asked for a session monicker; **Crumb** it is —
we drop a crumb in the log every time a banner appears, and follow the trail
later.
